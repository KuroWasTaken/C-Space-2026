## Description

Conception d'une carte électronique embarquée pour l'acquisition de données de vol d'une minifusée dans le cadre de la compétition nationale **C'Space** organisée par le CNES. La carte mesure pression et accélération en vol pour reconstituer la trajectoire.

> 🏆 Compétition nationale — validation par revues CNES

## Rôle

Chef de Projet — Club Aérospatial ISEN Nantes  
Responsable : conception électronique, routage PCB, dossier de conception, revues CNES.

## Contraintes respectées

- ✅ PCB multicouche (routage différentiel, plans de masse)
- ✅ Contraintes CEM (découplage, isolation, retour de masse)
- ✅ Conformité exigences méthodologiques CNES
- ✅ Revues de validation devant jury CNES

## Stack technique

- **EDA** : KiCad
- **Capteurs** : Pression · Accélération
- **Contraintes** : CEM · Masse embarquée · Environnement vibratoire
